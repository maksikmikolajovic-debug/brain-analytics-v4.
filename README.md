# BRAIN ANALYTICS V4 — мобільна PWA (MVP)

## Що працює
- Публічні свічки Binance Spot API: BTC/USDT, ETH/USDT, SOL/USDT; 5m, 15m, 1h, 4h.
- Графік 100 закритих свічок, EMA 9/21, RSI 14, ATR 14, підтримка/опір 20 свічок.
- Автоматичне оновлення раз на 60 секунд.
- Працює без облікового запису Binance, без ключів та без торгових операцій.

## Запуск із телефона Android через GitHub Pages
1. Розпакуйте ZIP у файловому менеджері Android.
2. Відкрийте github.com у браузері та створіть **публічний репозиторій** `brain-analytics-v4`.
3. Завантажте **всі чотири файли з папки** (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`) **у корінь репозиторію** (не саму папку).
4. В репозиторії відкрийте Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
5. Через кілька хвилин відкрийте URL, показаний у Pages, у Chrome на Android.
6. У меню Chrome виберіть «Додати на головний екран» / «Встановити додаток».

Якщо GitHub відкриває спрощену мобільну версію без потрібних кнопок, увімкніть у Chrome «Версія для комп’ютера».

## Обмеження
- Це **робочий перший інтерфейс**, а не готовий ШІ або прогноз із 98% точністю.
- Наразі **немає інтеграції Supabase**: її додамо наступним етапом з RLS та без розкриття service_role ключа.
- API Binance може бути недоступним у деяких мережах або регіонах. Якщо запит не вдається, програма показує помилку, а не вигадані ціни.
- PWA потребує HTTPS для інсталяції, GitHub Pages його надає.
